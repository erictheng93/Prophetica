# 黑金奢華設計系統 — Black Gold Luxury × Neumorphic Casino

> 本文件根據參考截圖萃取，融合三股風格血統：
> **A.** 黑金風格（Black & Gold Aesthetic）— 色彩制度
> **B.** 輕奢微立體（Light Luxury Neumorphism）— 表面物理
> **C.** 高端賭場美學（Luxury Casino Aesthetic）— 圖像學詞彙
>

---

## 1. 風格血統與融合邏輯

這個設計不是單一風格，是三股傳統的疊合：

| 血統 | 提供 | 來源傳統 |
|------|------|----------|
| **黑金風格** | 色彩制度、雙色控制力 | 私人銀行、奢侈品（百達翡麗、卡地亞夜場版） |
| **輕奢微立體** | 表面質感、可觸性、柔和高光 | 2020s soft luxury UI（Apple Vision Pro、Glassmorphism 後繼） |
| **高端賭場美學** | 圖像符號、儀式構圖、戲劇張力 | 澳門 / Monte Carlo / 拉斯維加斯 VIP 廳 |

**融合邏輯**：以黑金作為底層色彩語法，以微立體賦予「軟、暖、可觸」的表面，以賭場美學供應「皇冠、盾牌、籌碼、骰子、月桂」的圖像學詞彙與「中央加冕式」構圖。三者疊合產出的氣質是**儀式性的、敬畏性的、東方對「貴」的傳統理解**——與 Lamborghini 那種「冷感、銳利、工業」的奢華屬於對立的家族。

## 2. 視覺氛圍

整體調性：**夜場加冕（Nocturnal Coronation）**。

頁面是一個被金色光束從中央照亮的黑色舞台。背景**並非絕對純黑**，而是帶有極輕微的暖調漸層（中央偏暖，邊緣偏冷藍黑），製造「劇院內、聚光燈下」的空間感。從畫面中軸放射出細密的金色光線（god rays），光線之間漂浮著金粉與星芒粒子，密度由中心向外遞減。

主體始終置中。Hero 區是一個 3D 渲染的金色徽記（皇冠 + 盾牌 + 月桂環 + 賭場道具），坐落於一個淺金色的圓形舞台，舞台邊緣有一圈細金線勾邊。整個構圖讀起來是**儀式照、紀念碑、神龕**的視覺結構——而非產品照、人物照或場景照。

文案以中文襯線體（宋/明體）大字呈現詩意句子，氣質傾向**文學性、抒情性、東方哲學感**——而非廣告 slogan 的喊叫式語氣。標題下方常以較細的灰白色無襯線體鋪一行解釋性副文案。

按鈕是**軟金色藥丸**，帶有微妙的內側高光與外側陰影，看起來像可以按下去的金屬糖果或溫熱的金幣，**不是平的色塊**。

## 3. 色彩系統

### 3.1 主色（Primary）

| 名稱 | 色碼 | 用途 |
|------|------|------|
| Champagne Gold（香檳金） | `#D4A857` | 主強調色、CTA 按鈕主漸層中段 |
| Warm Gold Highlight | `#F0D78C` | 金色元素上緣高光、徽記亮部 |
| Deep Gold Shadow | `#8B6914` | 金色元素下緣陰影、徽記暗部 |
| Antique Gold | `#B8860B` | 邊框、分隔線、低調金色細節 |

**色相選擇要點**：絕對避免使用冷感檸檬黃調的金色（如 `#FFC000`、`#FFD700`）。本系統的金色必須是**暖色調、帶橙紅底色的香檳金**，這是與「賭場 VIP 廳」「東亞奢侈品」「19 世紀歐洲宮廷裝飾」對齊的關鍵。

### 3.2 背景色（Surface）

| 名稱 | 色碼 | 用途 |
|------|------|------|
| Velvet Black（絨黑） | `#0A0808` | 主背景，**非純黑** |
| Stage Black | `#000000` | 邊緣最深處、徽記後方暗部 |
| Elevated Panel | `#141010` | 卡片表面、可觸區塊底色 |
| Inset Well | `#050303` | 凹陷表面（neumorphic 凹槽底） |

**關鍵原則**：背景**不是平塗黑色**，而是一個由中心 `#1A1410`（暖黑）向四角 `#000000`（純黑）的徑向漸層。這個漸層是整個「劇場感」的物理基礎，沒有它，整套設計會塌陷成廉價的黑底金字。

### 3.3 文字色

| 名稱 | 色碼 | 用途 |
|------|------|------|
| Pure White | `#FFFFFF` | 大標題、按鈕內文字 |
| Pearl | `#EDE6D8` | 次要標題、徽記內文（暖白） |
| Smoke Gold | `#C9B98F` | 強調文字、引言、品牌標語 |
| Mist | `#8A8378` | 副文案、解釋性文字 |
| Ash | `#5C574E` | 禁用文字、極次要訊息 |

**所有文字色都帶暖色底**——不要使用純灰色（如 `#808080`），那會與暖金背景產生不和諧的色溫衝突。所有灰必須往黃褐色偏移。

### 3.4 功能色

| 名稱 | 色碼 | 用途 |
|------|------|------|
| Success Jade | `#5FAF7A` | 成功狀態、盈利數字（帶綠灰調，非鮮綠） |
| Danger Crimson | `#C4503F` | 危險、虧損、警告（暗紅，非鮮紅） |
| Info Sapphire | `#5878A8` | 資訊提示（深藍灰） |

所有功能色都**降低飽和度並暗化**，使其能與黑金主色和諧共存，不破壞奢華氣質。

| Caption | 中文無襯線 | 12–13px | 400 | 1.5 | 標籤、提示、metadata |
| Button | 中文無襯線 | 14–16px | 500 | 1.0 | 按鈕文字 |
| 大型數字 | Manrope | 24–48px | 600 | 1.0 | 賠率、金額、計數器 |

### 4.3 排版原則

- **標題用襯線、UI 用無襯線**——這是本系統最核心的字體規則。襯線承擔「優雅、權威、儀式感」，無襯線承擔「功能、清晰、現代」。
- **標題不使用 ALL CAPS**——中文沒有大小寫，而西文標題刻意採用 Title Case 或 Sentence case，保持文學感而非廣告感。與 Lamborghini 全大寫的喊叫式語氣形成對比。
- **行高寬鬆**——中文襯線標題行高 1.4，內文 1.7，呼應「劇場、留白、儀式」的氣質。
- **字距標準**——不刻意壓縮或拉伸字距，保持自然氣息。
- **不使用斜體**——奢華語境中斜體會顯得廉價或浮誇。

## 5. 輕奢微立體（Neumorphic Surfaces）

這是本系統最容易做壞、也最關鍵的層次。**不是 2020 年那種四處灰底凸起的 neumorphism**，而是**金屬感的、暗場內的微立體**。

### 5.1 核心原理

每一個可觸表面（按鈕、卡片、徽記、輸入框）都是**從黑色舞台中浮出或凹入的金屬塊**，光從上方斜照，產生：

- **上緣高光**：1px–2px 的暖金色或淺金色高光線
- **下緣陰影**：4px–8px 的深褐或純黑陰影，柔化
- **內側梯度**：表面本身有極輕微的上亮下暗漸層（不到 10% 明度差）
- **外側光暈**：可選的金色微弱發光環（CTA 才有）

### 5.2 凸起表面（Raised Surface）

```
box-shadow:
  inset 0 1px 0 rgba(240, 215, 140, 0.4),   /* 上緣高光 */
  inset 0 -1px 0 rgba(0, 0, 0, 0.6),         /* 下緣內陰 */
  0 4px 12px rgba(0, 0, 0, 0.6),             /* 外側陰影 */
  0 0 24px rgba(212, 168, 87, 0.15);         /* 金色光暈（選用）*/
```

### 5.3 凹陷表面（Inset Surface）

```
box-shadow:
  inset 0 2px 4px rgba(0, 0, 0, 0.8),        /* 上緣內陷陰影 */
  inset 0 -1px 0 rgba(212, 168, 87, 0.1);    /* 下緣微高光 */
background: linear-gradient(180deg, #050303 0%, #0A0808 100%);
```

### 5.4 金色按鈕的微立體

金色 CTA 按鈕是本系統 neumorphism 的最高表現，包含**四層疊加**：

1. **底色漸層**：上 `#F0D78C` → 中 `#D4A857` → 下 `#A68340`（縱向）
2. **上緣高光線**：1px 內陰高光 `rgba(255, 240, 200, 0.6)`
3. **下緣陰影線**：1px 內陰陰影 `rgba(80, 50, 0, 0.5)`
4. **外發光暈**：`0 0 32px rgba(212, 168, 87, 0.4)` 製造「金屬發燙」感

按下狀態時，漸層方向反轉（上暗下亮），外發光減弱，模擬實體按壓。

### 5.5 卡片表面

卡片底色 `#141010`，邊框 `1px solid rgba(212, 168, 87, 0.25)`（細金線），上緣高光 `inset 0 1px 0 rgba(212, 168, 87, 0.15)`，外側陰影 `0 8px 32px rgba(0, 0, 0, 0.8)`。**圓角 16–24px**——絕對不用直角，這是與 Lamborghini 系統的另一個本質區別。

### 5.6 禁忌

- ❌ **不要使用灰底灰凸**的傳統 neumorphism——那是淺色 UI 的玩法，在黑金語境下會顯得疲軟。
- ❌ **不要對所有元素施加 neumorphism**——只對「可觸、可點、可聚焦」的元素施加。裝飾文字、分隔線、背景區塊保持平面。
- ❌ **不要過度模糊陰影半徑**——黑場中過大的模糊半徑會吃掉對比，建議陰影模糊半徑 ≤ 16px（光暈除外）。

## 6. 元件樣式

### 6.1 主要 CTA（Primary Button）

- **形狀**：圓角藥丸（border-radius: 999px 或元件高度的一半）
- **填色**：縱向金色漸層 `#F0D78C → #D4A857 → #A68340`
- **文字**：純黑 `#000000`，14–16px，字重 500，無字距變化
- **內距**：縱 12–14px，橫 28–32px
- **微立體**：依 §5.4 完整四層
- **Hover**：金色更亮，外發光暈擴大 20%
- **Active/Pressed**：漸層反轉（上暗下亮），外發光暈消失
- **Disabled**：金色降至 30% 飽和度，移除外發光

### 6.2 次要 CTA（Ghost Button）

- **形狀**：圓角藥丸（同主 CTA）
- **填色**：完全透明
- **邊框**：1.5px solid `#D4A857`
- **文字**：`#EDE6D8`（珍珠白），同主 CTA 字級
- **微立體**：僅有極輕外發光 `0 0 16px rgba(212, 168, 87, 0.2)`
- **Hover**：邊框變亮為 `#F0D78C`，背景填入 `rgba(212, 168, 87, 0.08)`
- **不用**：白色邊框、灰色邊框——金邊是辨識度核心

### 6.3 註冊/登入 雙態按鈕

截圖中可見「未登入 / 登入 / 註冊」三聯體：
- **未登入**：純文字標籤，灰色 `#8A8378`
- **登入**：純文字按鈕，白色 `#FFFFFF`
- **註冊**：金色實心藥丸（依 §6.1 主 CTA）

### 6.4 卡片（Card）

- **背景**：`#141010` 或徑向漸層 `radial-gradient(circle at top, #1A1410 0%, #0A0808 100%)`
- **圓角**：16–24px
- **邊框**：1px solid `rgba(212, 168, 87, 0.2–0.3)` 細金線
- **陰影**：`0 8px 32px rgba(0, 0, 0, 0.8)` 外側 + 上緣金色內高光
- **內距**：24–32px
- **標題**：襯線體，金色或珍珠白
- **內容**：無襯線體，灰白色

### 6.5 輸入框（Input）

- **背景**：凹陷 inset 表面（依 §5.3）
- **邊框**：1px solid `rgba(212, 168, 87, 0.15)` 極細金線
- **圓角**：12px
- **文字**：`#EDE6D8`
- **placeholder**：`#5C574E`
- **focus**：邊框變為 `#D4A857`，外發光 `0 0 0 3px rgba(212, 168, 87, 0.15)`

### 6.6 導覽列（Navigation）

- **背景**：完全透明，貼在主背景上
- **連結文字**：`#EDE6D8`，無襯線 14–16px
- **active 狀態**：金色 `#D4A857` + 下方 2px 金色底線
- **語言選擇器**：藥丸形 ghost button 樣式
- **無底色 bar、無分隔線**——所有元素懸浮在絨黑上

### 6.7 徽章/標籤（Badge）

- 圓角藥丸或圓角 6px
- 背景：`rgba(212, 168, 87, 0.12)` 半透明金
- 邊框：1px solid `rgba(212, 168, 87, 0.3)`
- 文字：`#D4A857`，12px，字重 500

## 7. Hero 構圖與徽記系統

這是本系統的**戲劇核心**，也是最容易與 SPEC-001 衝突的層次。

### 7.1 中央加冕式構圖（Coronation Composition）

Hero 區永遠採用**單一焦點、中軸對稱、底部托盤**的構圖：

```
        ╱光╲
       ╱  ╲
   ★ ★ ★ ★ ★ ★      ← 上方粒子與光束
       【徽記】       ← 中央 3D 金色物件
   ━━━━●━━━━        ← 底部圓盤舞台 + 倒影
       ╲ ╱
        ╲╱
```

- **垂直構圖**：上 1/3 留白給光線與粒子，中 1/3 放主徽記，下 1/3 放舞台、倒影與光暈
- **對稱性**：嚴格中軸對稱，左右元素鏡像配置
- **景深**：徽記前方有少量飄落粒子（前景），後方有放射光束（背景），製造**三層空間感**

### 7.2 徽記系統（Emblem）

主徽記是一個 3D 渲染的金色複合物件，傳統組成元素：

| 元素 | 象徵 | 視覺處理 |
|------|------|----------|
| **皇冠**（Crown） | 權威、頂峰、王者 | 立於盾牌上方，多尖頂 |
| **盾牌**（Shield） | 守護、品牌承載 | 中央放品牌字標（如「JSX」） |
| **月桂環**（Laurel） | 榮譽、勝利、古典 | 環繞盾牌左右兩側 |
| **籌碼**（Chips） | 賭場、籌碼 ⚠️ | 漂浮於徽記兩側 |
| **骰子**（Dice） | 機率、博弈 ⚠️ | 落於舞台邊緣 |
| **撲克元素**（Cards/Suits） | 牌桌 ⚠️ | 散落或漂浮 |

**渲染風格**：3D 拉絲金屬質感，邊緣銳利反光，表面有輕微凹凸雕花紋路，整體光源來自正上方偏前 45°，產生「神龕內聚光燈下展示」的效果。

### 7.3 舞台（Podium）

徽記下方永遠有一個**金色橢圓盤**作為基座：
- 外觀：薄金色橢圓環，內部漸層至透明
- 倒影：徽記在盤面有約 30% 透明度的金色倒影
- 光暈：盤面下方有放射狀地面光暈
- 邊緣：細金線勾邊

### 7.4 命名建議

不要在程式碼中以「casino emblem」「gambling logo」命名這些元素，建議統一命名為：
- `HeroEmblem` / `BrandSigil` / `CenterpieceMonument`
- 即使內容是博弈道具，命名層保持中性

## 8. 光效與粒子（Lighting & Particles）

### 8.1 神光（God Rays）

從畫面中央上方放射的金色光束，是本系統的環境基調。

- **顏色**：`rgba(240, 215, 140, 0.15)` 至 `rgba(255, 220, 130, 0.05)` 漸變
- **數量**：6–12 道，不均勻角度散布（避免機械感）
- **長度**：可達畫面 60–80% 高度
- **混合模式**：`screen` 或 `lighten`，疊加於背景之上
- **動畫**（選用）：極緩慢旋轉（30–60 秒一圈）或脈動（呼吸感）

### 8.2 金粉粒子（Gold Dust）

- **形狀**：1–3px 的圓形光點
- **顏色**：`#F0D78C` 至 `#FFFFFF` 之間隨機
- **不透明度**：30%–80% 隨機
- **數量**：100–300 顆，密度由中心向外遞減
- **動畫**：緩慢向上飄移 + 隨機橫向漂動，類似螢火蟲

### 8.3 星芒（Starburst）

少量大型星芒（5–10 個），分布於畫面邊緣與徽記附近：
- 形狀：四點或六點星
- 大小：8–24px
- 顏色：白核 + 金色外暈
- 用途：點綴重點區域、製造夢幻感

### 8.4 光暈（Glow Halos）

- **徽記後方**：大型徑向金色光暈，半徑可達徽記的 2 倍
- **CTA 按鈕**：依 §5.4 描述
- **卡片懸停**：邊框金色光暈加亮

### 8.5 性能注意

這些光效若用 PNG/SVG 圖層疊加，總檔案大小應壓縮在 200KB 以內。若用 CSS/Canvas 動態繪製，應限制 requestAnimationFrame 幀率為 30fps 並考慮 `prefers-reduced-motion` 用戶偏好。

## 9. 版面節奏

### 9.1 間距系統

- **基本單位**：4px
