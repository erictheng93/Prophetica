Implementation Plans

本目錄集中存放「Implementation Plan / 執行書 / 實作書」文件，避免與 specs/ 規格文件混淆。

本地目錄快速連結

  • ➜../../specs（規格文件存放）
  • ➜./（實作書/執行書存放）

文件分類規則

  • 規格正文（SPEC 文件）：放在 specs/，例如 specs/SPEC-XXX-... .html
  • 實作書/執行書：放在 docs/implementation-plans/，例如 SPEC-011-affiliate-commission-implementation-plan.html、SPEC-xxx-...-execution-plan.html
  • specs/SPEC-000-index.html 為 Master Index，只維護跨 SPEC 索引、launch gate 與決策追蹤；不建立獨立 implementation plan。SPEC-001 目前保留未使用。
